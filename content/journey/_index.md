---
title: The Journey
description: >-
  Six chapters (five professional, one of personal research), one repeating pattern: identify the system constraining
  progress, build the capability that removes the constraint, apply it at greater scale.
---

This is not a chronology; it is a compounding loop. Each chapter ends with the
capability that made the next one possible, and each chapter's constraint sits one
level above the last: first the code, then the platform, then the engineers, then the
company, then the strategy. The sixth chapter is personal research rather than a
role: what happens to the enterprise itself when agents join it. Read it in order, or start
at the scale that interests you.
